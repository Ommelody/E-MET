THAMC e-Material — Inventory & Requisition Management System

เอกสารประกอบการพิจารณาอนุมัติงบประมาณ

๑. บทสรุปสำหรับผู้บริหาร

ระบบ THAMC e-Material เป็นระบบสารสนเทศบริหารจัดการการเบิกจ่ายวัสดุและพัสดุคงคลังแบบครบวงจรผ่านเว็บเบราว์เซอร์ ทดแทนการทำงานด้วยเอกสารและการบันทึกด้วยมือ ครอบคลุมกระบวนการตั้งแต่การร้องขอเบิก การอนุมัติตามลำดับชั้น การจ่ายพัสดุ การรับพัสดุเข้าคลัง การคำนวณจุดสั่งซื้ออัตโนมัติ ตลอดจนการจัดทำรายงานและการตรวจสอบย้อนหลัง โดยรองรับการใช้งานทั้งบนคอมพิวเตอร์และโทรศัพท์มือถือ

ประโยชน์ที่คาดว่าจะได้รับ: ลดความคลาดเคลื่อนของข้อมูลคงคลัง · ลดเวลาและกระดาษในกระบวนการเบิกจ่าย · เพิ่มความโปร่งใสด้วยการอนุมัติตามลำดับชั้นและบันทึกการใช้งาน · ควบคุมงบจัดซื้อด้วยระบบคำนวณจุดสั่งซื้ออัตโนมัติ

๒. ขอบเขตความสามารถของระบบ (Functional Overview)

จัดการคลังพัสดุ
บันทึก/แก้ไข/ค้นหาวัสดุ พร้อมรูปภาพ กำหนดจุดสั่งซื้อขั้นต่ำและจำนวนเบิกสูงสุด แจ้งเตือนของใกล้หมด
เบิก–อนุมัติ–จ่าย
สร้างใบเบิก อนุมัติตามลำดับชั้น (หัวหน้างาน → พัสดุ) ปรับยอดอนุมัติ/จ่ายจริง รองรับจ่ายบางส่วนและของค้างจ่าย
อนุมัติแบบชุด (Batch)
กรองช่วงวันที่ เลือกหลายใบพร้อมกัน แตกรายการปรับยอดในตัว ลดเวลาการทำงานของผู้อนุมัติ
รับพัสดุเข้าคลัง
บันทึกด้วยตนเองหรือนำเข้าจากไฟล์ Excel ปรับปรุงคงคลังและราคาต่อหน่วยอัตโนมัติ
จุดสั่งซื้ออัตโนมัติ
คำนวณจากอัตราการใช้จริง แนะนำปริมาณและมูลค่าที่ควรสั่ง ออกใบขอซื้อเป็น Excel
ตรวจสอบการเคลื่อนไหว
ค้นหาพัสดุแล้วดูประวัติรับเข้า/จ่ายออกทั้งหมด พร้อมวันที่และปลายทาง
รายงาน & เอกสาร
รายงาน ๑๐ ประเภท กรองตามช่วงเวลา/หน่วยงาน/หมวดหมู่ ส่งออก Excel และพิมพ์เอกสาร/ใบนับสต๊อกเป็น PDF
QR & โมบาย
พิมพ์ป้าย Location พร้อม QR สแกนด้วยมือถือเพื่อดู/ปรับปรุงสต๊อก รองรับการติดตั้งเป็นแอปบนหน้าจอมือถือ
ผู้ใช้ & สิทธิ์
กำหนดสิทธิ์ ๔ ระดับ (Admin/Manager/Staff/User) จัดการผู้ใช้และหน่วยงาน
บันทึกการใช้งาน (Audit)
เก็บประวัติการกระทำสำคัญ ใครทำอะไรเมื่อไหร่ เพื่อความโปร่งใสและตรวจสอบย้อนหลัง

๓. กระบวนการทำงานหลัก (Workflow)

ผู้ใช้สร้างใบเบิก→ หัวหน้างานอนุมัติ→ เจ้าหน้าที่พัสดุจ่ายของ→ ตัดสต๊อก + ออกใบจ่าย→ เสร็จสิ้น / ตรวจสอบย้อนหลัง

ทุกขั้นตอนบันทึกสถานะและผู้ดำเนินการ พร้อมสร้างเอกสารใบเบิก/ใบจ่ายที่พิมพ์และบันทึกเป็น PDF ได้ และตัดยอดคงคลังโดยอัตโนมัติเมื่อมีการจ่ายจริง

๔. สถาปัตยกรรมระบบ (System Architecture)

ผู้ใช้งาน
คอมพิวเตอร์ / โทรศัพท์มือถือ ผ่านเว็บเบราว์เซอร์ (ไม่ต้องติดตั้งโปรแกรม) เชื่อมต่อแบบเข้ารหัส HTTPS
ส่วนหน้า
Frontend
React + Vite — ส่วนแสดงผลและโต้ตอบผู้ใช้ รองรับการแสดงผลแบบ Responsive ทุกขนาดหน้าจอ
ส่วนประมวลผล
Backend
Node.js + Express — ประมวลผลตรรกะทางธุรกิจ ควบคุมสิทธิ์การเข้าถึง และเป็นตัวกลางเดียวที่เชื่อมต่อฐานข้อมูล (ปกป้องคีย์ลับไม่ให้รั่วไหล)
ฐานข้อมูล
Database
Supabase (PostgreSQL) — จัดเก็บข้อมูลทุกตาราง และพื้นที่จัดเก็บไฟล์ (Storage) สำหรับเอกสารและรูปภาพ

สถาปัตยกรรมแบบ ๓ ชั้น (Three-tier) แยกส่วนแสดงผล ส่วนประมวลผล และฐานข้อมูลออกจากกันอย่างชัดเจน — ส่วนประมวลผลและฐานข้อมูลเป็นคนละบริการ หากส่วนประมวลผลขัดข้อง ข้อมูลในฐานข้อมูลยังคงปลอดภัยครบถ้วน

เทคโนโลยีที่ใช้

ส่วนประกอบเทคโนโลยีรูปแบบการให้บริการ
ส่วนแสดงผล (Frontend)React, Vite, Tailwind CSSWeb Application
ส่วนประมวลผล (Backend)Node.js, ExpressCloud Hosting (Render)
ฐานข้อมูล (Database)PostgreSQLSupabase (Cloud, มีระบบสำรองข้อมูล)
ที่จัดเก็บไฟล์ (Storage)Supabase StorageCloud Object Storage

๕. ความปลอดภัยและความต่อเนื่องของระบบ

  • ควบคุมสิทธิ์การเข้าถึง ตามบทบาทผู้ใช้ ๔ ระดับ และเข้ารหัสรหัสผ่านตามมาตรฐาน (bcrypt)
  • คีย์เชื่อมต่อฐานข้อมูล ถูกเก็บฝั่งเซิร์ฟเวอร์เท่านั้น ไม่เปิดเผยต่อผู้ใช้
  • บันทึกการใช้งาน (Audit Log) ตรวจสอบย้อนหลังได้ว่าใครทำรายการใด เมื่อใด
  • การสำรองข้อมูล อัตโนมัติรายวันในระดับผู้ให้บริการฐานข้อมูล พร้อมเครื่องมือสำรองข้อมูลเสริมที่ควบคุมเอง
  • เป้าหมายการกู้คืน ระบบกลับมาใช้งานได้ภายใน ~๒ ชั่วโมง (RTO) ข้อมูลย้อนหลังไม่เกิน ๒๔ ชั่วโมง (RPO)

๖. ประมาณการค่าใช้จ่ายในการดำเนินระบบ (ต่อเนื่อง)

รายการรูปแบบประมาณการ/เดือน
ค่าบริการเซิร์ฟเวอร์ประมวลผล (Backend Hosting)รายเดือน~๒๕๐–๗๐๐ บาท
ค่าบริการฐานข้อมูล + สำรองข้อมูล (Database)รายเดือน~๙๐๐ บาท
รวมค่าดำเนินระบบโดยประมาณ~๑,๒๐๐–๑,๖๐๐ บาท/เดือน
หมายเหตุ: ประมาณการข้างต้นเป็นค่าโครงสร้างพื้นฐานคลาวด์สำหรับการใช้งานจริงระดับองค์กร (อัตราแลกเปลี่ยนโดยประมาณ) ยังไม่รวมค่าพัฒนา/ปรับแต่งระบบ ค่าดูแลบำรุงรักษา และค่าฝึกอบรม ซึ่งขึ้นกับข้อตกลงการให้บริการ

๗. ข้อเสนอเพื่อการพิจารณา

  • ระบบพัฒนาเสร็จและใช้งานได้จริงแล้ว สามารถเริ่มใช้งานได้ทันทีหลังการเตรียมข้อมูลตั้งต้นและฝึกอบรม
  • ใช้โครงสร้างพื้นฐานแบบคลาวด์ ค่าใช้จ่ายคงที่รายเดือน ไม่ต้องลงทุนเซิร์ฟเวอร์ฮาร์ดแวร์
  • รองรับการต่อยอด เช่น การแจ้งเตือนผ่านอีเมล/LINE การเชื่อมต่อระบบ SAP และการขยายไปหลายหน่วยงาน
