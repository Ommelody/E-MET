โครงการพัฒนาคุณภาพหน่วยงาน
ศูนย์การแพทย์ธรรมศาสตร์ โรงพยาบาลธรรมศาสตร์เฉลิมพระเกียรติ
ประจำปีงบประมาณ 2568
1. ชื่อโครงการ : พัฒนาระบบการเบิกจ่ายพัสดุสำนักงานศูนย์การแพทย์ (THAMC e-Material)
2. ผู้รับผิดชอบโครงการ : นายสวรินทร์ ศรีเกษ ตำแหน่ง นักตรวจสอบภายในปฏิบัติหน้าที่นักวิชาการพัสดุ

3. หลักการและเหตุผล

ปัจจุบัน การเบิกจ่ายพัสดุสำนักงานภายในศูนย์การแพทย์ธรรมศาสตร์ ยังคงพบข้อจำกัดเนื่องจากต้องดำเนินการผ่านระบบ SAP (System Applications and Products in Data Processing) ซึ่งถูกออกแบบมาสำหรับการบริหารจัดการทรัพยากรขนาดใหญ่ของโรงพยาบาลเป็นหลัก และมีข้อจำกัดด้าน License ในการเข้าถึง ทำให้บุคลากรผู้ใช้งานทั่วไปไม่สามารถเข้าถึงระบบเพื่อดำเนินการเบิกพัสดุสำนักงานได้โดยตรง การดำเนินการเบิกจ่ายจึงยังคงต้องพึ่งพากระบวนการแบบ Manual หรือการประสานงานผ่านผู้ดูแลคลังพัสดุ ส่งผลให้เกิดความล่าช้าในการอนุมัติและการรับพัสดุ ไม่สะดวกต่อผู้ใช้งาน อีกทั้งยังขาดระบบการบันทึกข้อมูลที่ชัดเจนและเป็นระเบียบ ทำให้การตรวจสอบย้อนหลัง การรวบรวมข้อมูลเพื่อวิเคราะห์การใช้จ่ายพัสดุ และการบริหารจัดการคลังพัสดุเป็นไปได้ยากและไม่มีประสิทธิภาพเท่าที่ควร

เพื่อแก้ไขปัญหาและข้อจำกัดดังกล่าวข้างต้น โครงการ "พัฒนาระบบการเบิกจ่ายพัสดุสำนักงานศูนย์การแพทย์ THAMC e-Material" จึงถูกพัฒนาขึ้น โดยมีวัตถุประสงค์เพื่อสร้างระบบการเบิกจ่ายพัสดุสำนักงานที่เป็น Web Application แยกต่างหากจากระบบ SAP แต่ยังคงความสามารถในการบันทึกข้อมูลที่จำเป็น โดยพัฒนาด้วยเทคโนโลยีเว็บสมัยใหม่ (React, Node.js) และใช้ฐานข้อมูล Supabase (PostgreSQL) ซึ่งเป็นเทคโนโลยีที่มีความยืดหยุ่นสูง รองรับการขยายงาน และมีค่าใช้จ่ายโครงสร้างพื้นฐานต่ำ ระบบนี้จะช่วยอำนวยความสะดวกให้บุคลากรผู้ใช้งานทั่วไปสามารถเข้าถึงและดำเนินการเบิกจ่ายพัสดุได้ด้วยตนเองผ่านช่องทางดิจิทัลที่เข้าถึงง่าย ลดขั้นตอนการทำงาน ลดความผิดพลาดจาก human error เพิ่มความรวดเร็วและโปร่งใสในการอนุมัติและเบิกจ่าย

นอกจากนี้ ระบบ THAMC e-Material ยังช่วยสนับสนุนการทำงานในด้านต่าง ๆ อย่างเป็นระบบมากยิ่งขึ้น ได้แก่:

  • การพัฒนาช่องทางการเบิก : เปลี่ยนจากกระบวนการแบบ Manual หรือการประสานงานที่ซับซ้อน ไปสู่ช่องทางออนไลน์ที่สะดวก รวดเร็ว และเข้าถึงได้ตลอดเวลา ทั้งบนคอมพิวเตอร์และโทรศัพท์มือถือ
  • การเก็บข้อมูล : บันทึกข้อมูลการเบิกจ่ายได้อย่างละเอียดและเป็นระบบ สามารถตรวจสอบย้อนหลังได้ง่าย ลดปัญหาเอกสารสูญหาย
  • การรายงาน : สามารถดึงข้อมูลเพื่อสร้างรายงานสรุปการเบิกจ่ายตามหน่วยงาน ประเภทพัสดุ หรือช่วงเวลา เพื่อใช้ในการวิเคราะห์และวางแผนการจัดซื้อได้อย่างมีประสิทธิภาพ
  • การตรวจสอบ : เพิ่มความโปร่งใสและตรวจสอบได้ในทุกขั้นตอนของการเบิกจ่าย ด้วยระบบบันทึกการใช้งาน (Audit Log)
  • การปฏิบัติงานอย่างมีระบบ : ส่งเสริมให้บุคลากรคุ้นชินกับการใช้เทคโนโลยีในการทำงาน เพิ่มทักษะด้านดิจิทัล และสร้างวัฒนธรรมการทำงานที่ทันสมัย ตอบรับยุคดิจิทัล

โครงการนี้จึงไม่เพียงแต่เป็นการแก้ไขปัญหาเฉพาะหน้า แต่ยังเป็นการวางรากฐานสำคัญในการยกระดับประสิทธิภาพการบริหารจัดการพัสดุของศูนย์การแพทย์ธรรมศาสตร์ให้เป็นไปอย่างมีระบบ สะดวก รวดเร็ว และเป็นมิตรกับสิ่งแวดล้อมยิ่งขึ้น

4. วัตถุประสงค์

4.1 เพื่อแก้ไขปัญหาข้อจำกัดช่องทางการเบิกจ่ายพัสดุสำนักงาน โดยให้บุคลากรสามารถเข้าถึงและดำเนินการเบิกจ่ายได้สะดวกยิ่งขึ้น

4.2 เพื่อเพิ่มประสิทธิภาพและความรวดเร็วในการปฏิบัติงานเบิกจ่ายพัสดุ ลดขั้นตอนและลดความผิดพลาดที่เกิดจากระบบ Manual

4.3 เพื่อให้มีข้อมูลการเบิกจ่ายพัสดุที่เป็นระบบ สามารถนำไปวิเคราะห์ วางแผนการจัดซื้อ และตรวจสอบย้อนหลังได้อย่างมีประสิทธิภาพ

5. วิสัยทัศน์ พันธกิจ ค่านิยม THAM-C

โครงการ "พัฒนาระบบการเบิกจ่ายพัสดุสำนักงานศูนย์การแพทย์ THAMC e-Material" สอดคล้องกับวิสัยทัศน์ พันธกิจ และค่านิยมของศูนย์การแพทย์ธรรมศาสตร์ (THAM-C) ในหลายมิติ โดยเฉพาะอย่างยิ่งในด้านการส่งเสริมความคิดสร้างสรรค์สู่นวัตกรรม (Creation) และการนำเทคโนโลยีมาประยุกต์ใช้ (Technology) ในการพัฒนาระบบการทำงานให้ทันสมัยและมีประสิทธิภาพยิ่งขึ้น ดังนี้:

  • โครงการนี้เป็นการนำเทคโนโลยีดิจิทัล (Web Application, React, Node.js, ฐานข้อมูลคลาวด์) มาประยุกต์ใช้เพื่อพัฒนากระบวนการเบิกจ่ายพัสดุ ซึ่งเป็นการยกระดับสู่การทำงานแบบดิจิทัล ลดการใช้กระดาษ และเพิ่มความรวดเร็ว
  • ระบบที่ใช้งานง่ายจะช่วยลดภาระงานและความยุ่งยากให้แก่บุคลากร ทำให้สามารถเข้าถึงพัสดุที่จำเป็นสำหรับการทำงานได้อย่างรวดเร็วและสะดวกสบาย ส่งเสริมสภาพแวดล้อมการทำงานที่ดีขึ้น
  • ระบบจะช่วยสร้างความโปร่งใสและตรวจสอบย้อนหลังได้ในทุกขั้นตอนของการเบิกจ่าย ทำให้การบริหารจัดการพัสดุเป็นไปอย่างมีประสิทธิภาพและรับผิดชอบต่อการใช้ทรัพยากร
  • การพัฒนาระบบนี้เป็นการส่งเสริมการบริหารจัดการพัสดุที่ทันสมัย เป็นระบบ และนำข้อมูลไปใช้ในการวางแผนได้ในอนาคต สอดคล้องกับการมุ่งเน้นความทันสมัยในการบริหารจัดการ
  • การริเริ่มพัฒนาระบบเบิกจ่ายพัสดุภายนอกข้อจำกัดของ SAP โดยใช้เทคโนโลยีเว็บสมัยใหม่ ถือเป็นการแสดงออกถึงความคิดสร้างสรรค์ในการแก้ไขปัญหา และการปรับปรุงกระบวนการทำงานให้ดีขึ้นด้วยนวัตกรรมที่เหมาะสมกับบริบทขององค์กร

โดยรวมแล้ว โครงการนี้สะท้อนถึงความมุ่งมั่นของศูนย์การแพทย์ในการนำนวัตกรรมและเทคโนโลยีมาใช้เพื่อยกระดับประสิทธิภาพการดำเนินงานภายใน สนับสนุนการทำงานของบุคลากร และก้าวไปสู่การเป็นองค์กรที่มีความทันสมัยและเป็นเลิศ

6. วิธีดำเนินการ

ออกแบบและพัฒนาระบบสำหรับเบิกจ่ายพัสดุในรูปแบบ Web Application โดยพัฒนาส่วนหน้า (Frontend) ด้วย React และส่วนประมวลผล (Backend) ด้วย Node.js เชื่อมต่อฐานข้อมูล Supabase (PostgreSQL) พร้อมพื้นที่จัดเก็บไฟล์เอกสารและรูปภาพ ให้บริการผ่านโครงสร้างพื้นฐานคลาวด์ เพื่อให้สามารถเข้าถึงได้ง่ายผ่านเว็บเบราว์เซอร์ทั้งบนคอมพิวเตอร์และโทรศัพท์มือถือ และไม่จำเป็นต้องติดตั้งโปรแกรมเพิ่มเติมบนเครื่องของผู้ใช้งาน

7. แผนงานย่อย / ขั้นตอนการดำเนินโครงการ

ลำดับที่ขั้นตอนการดำเนินงานระยะเวลาผู้รับผิดชอบผลลัพธ์ที่คาดหวัง
Phase 1: การวิเคราะห์และวางแผน
7.1วิเคราะห์ปัญหาปัจจุบันและรวบรวมความต้องการ (Requirement Gathering) จากผู้ใช้งานและผู้ที่เกี่ยวข้อง40 ชั่วโมงผู้รับผิดชอบโครงการและทีมงานรายละเอียดความต้องการ (Functional & Non-functional Requirements) และ Workflow การเบิกจ่ายพัสดุ
Phase 2: การออกแบบและพัฒนา
7.2ออกแบบโครงสร้างระบบ (Database Schema, UI/UX Design) และ Workflow การอนุมัติ80 ชั่วโมงผู้รับผิดชอบโครงการเอกสารการออกแบบระบบ, Mock-up UI
7.3เขียนระบบด้วย React และ Node.js เชื่อมโยงกับฐานข้อมูล Supabase (PostgreSQL)40 ชั่วโมงผู้รับผิดชอบโครงการระบบต้นแบบที่มีฟังก์ชันพื้นฐานครบถ้วน
Phase 3: การทดสอบและปรับใช้
7.4ทดสอบการใช้งานระบบ (User Acceptance Test - UAT) โดยกลุ่มผู้ใช้งานตัวอย่าง และแก้ไขปัญหา/ข้อบกพร่องที่พบ28 ชั่วโมงผู้รับผิดชอบโครงการและผู้ใช้งานทดสอบรายงานข้อผิดพลาด, ระบบที่ได้รับการแก้ไข
7.5ขึ้น Production และเปิดใช้งานจริง (Go-Live)28 ชั่วโมงผู้รับผิดชอบโครงการระบบพร้อมใช้งาน
Phase 4: การอบรมและประเมินผล
7.6จัดอบรมการใช้งานระบบให้แก่ผู้เกี่ยวข้อง (ผู้เบิก, ผู้อนุมัติ, ผู้จ่ายพัสดุ)24 ชั่วโมงผู้รับผิดชอบโครงการผู้ใช้งานสามารถใช้ระบบได้
7.7ติดตาม ประเมินผลการใช้งาน และปรับปรุงระบบอย่างต่อเนื่องตลอดโครงการหลังใช้ระบบผู้รับผิดชอบโครงการระบบมีประสิทธิภาพและตอบสนองความต้องการผู้ใช้งานได้ดี

8. Key Results หรือตัวชี้วัด

ตัวชี้วัด (KPIs)ค่าเป้าหมายวิธีการวัดระยะเวลาการวัด
8.1 ด้านประสิทธิภาพและความสะดวกในการใช้งาน (จากวัตถุประสงค์ 4.1 และ 4.2)
8.1.1 อัตราการใช้งานระบบ THAMC e-Material ของหน่วยงาน/บุคลากรที่เกี่ยวข้อง ไม่น้อยกว่า 90% ของหน่วยงานในศูนย์การแพทย์> 90%ตรวจสอบจากจำนวนผู้ใช้งานที่ลงทะเบียนและทำรายการในระบบภายใน 3 เดือนหลังเปิดใช้งาน
8.1.2 ความพึงพอใจของผู้ใช้งาน (ผู้เบิก, ผู้อนุมัติ, ผู้จ่าย) ต่อความสะดวกและรวดเร็วในการใช้งานระบบ ไม่น้อยกว่า 85%> 85%แบบสอบถามความพึงพอใจออนไลน์ภายใน 3 เดือนหลังเปิดใช้งาน
8.1.3 ระยะเวลาในการอนุมัติและเบิกจ่ายพัสดุ (ตั้งแต่ผู้เบิกส่งคำขอจนถึงรับพัสดุ) ภายในระยะเวลาที่กำหนดภายใน 7 วันเปรียบเทียบข้อมูลก่อนและหลังการใช้ระบบภายใน 3 เดือนหลังเปิดใช้งาน
8.2 ด้านข้อมูลและการบริหารจัดการ (จากวัตถุประสงค์ 4.3)
8.2.1 อัตราความผิดพลาดในการเบิกจ่ายพัสดุ (เช่น รายการผิด, จำนวนผิด) ลดลงจากระบบเดิม< 10%ตรวจสอบจากบันทึกข้อผิดพลาด เปรียบเทียบข้อมูลก่อนและหลังการใช้ระบบภายใน 6 เดือนหลังเปิดใช้งาน
8.2.2 ความสามารถในการดึงรายงานสรุปการเบิกจ่าย (เช่น ตามหน่วยงาน, ประเภทพัสดุ) ภายใน 30 นาทีภายใน 30 นาทีทดสอบการดึงรายงานและจัดประชุมเพื่อประเมินการนำข้อมูลไปใช้ภายใน 3 เดือนหลังเปิดใช้งาน
8.2.3 จำนวนครั้งที่สามารถใช้ข้อมูลจากระบบในการวางแผนการจัดซื้อพัสดุ ไม่น้อยกว่า 2 ครั้งต่อปี> 2 ครั้ง/ปีตรวจสอบรายงานการสั่งซื้อพัสดุประจำปีทุก 6 เดือนหลังเปิดใช้งาน
