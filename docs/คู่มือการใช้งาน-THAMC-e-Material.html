คู่มือการใช้งานระบบ THAMC e-Material

ระบบบริหารจัดการการเบิกจ่ายวัสดุและพัสดุคงคลัง
ฉบับผู้ใช้งาน · ปรับปรุงล่าสุด กรกฎาคม 2568

บทที่ ๑ · ภาพรวมระบบและสิทธิ์การใช้งาน

ระบบ THAMC e-Material เป็นระบบบริหารการเบิกจ่ายวัสดุแบบครบวงจร ทำงานผ่านเว็บเบราว์เซอร์ทั้งบนคอมพิวเตอร์และมือถือ ผู้ใช้แต่ละคนจะเห็นเมนูและทำงานได้ตามสิทธิ์ (Role) ที่ได้รับ

ระดับสิทธิ์การใช้งาน (Role)

สิทธิ์ขอบเขตการใช้งาน
User ผู้ใช้ทั่วไปสร้างใบเบิก ดูประวัติใบเบิกของตนเอง ดูประกาศ และแก้ไขโปรไฟล์ตนเอง
Staff เจ้าหน้าที่พัสดุสิทธิ์ของ User + จัดการคลังพัสดุ จ่ายพัสดุ (Stock) รับเข้าคลัง ตรวจการเคลื่อนไหว รายงาน จุดสั่งซื้อ Good Issue SAP
Manager ผู้จัดการสิทธิ์ของ Staff + อนุมัติใบเบิกขั้นหัวหน้างาน + บังคับปิดงาน
Admin ผู้ดูแลระบบสิทธิ์ทั้งหมด + จัดการผู้ใช้/แผนก + แก้ไขประกาศ + ดูบันทึกการใช้งาน (Audit Log)
การเข้าสู่ระบบ: เปิดเว็บระบบ → กรอกชื่อผู้ใช้และรหัสผ่าน → กด "เข้าสู่ระบบ" ผู้ใช้ใหม่กดแท็บ "ลงทะเบียน" เพื่อสร้างบัญชี (ผู้ดูแลระบบจะกำหนดสิทธิ์ให้ภายหลัง)
ใช้งานบนมือถือ: เพิ่มระบบไว้ที่หน้าจอโฮมได้ (Add to Home Screen) เพื่อเปิดใช้เหมือนแอป — เมนูหลักอยู่แถบด้านล่างจอ ปุ่ม "เพิ่มเติม" เปิดเมนูทั้งหมด

บทที่ ๒ · คู่มือรายเมนู

๒.๑ ประกาศข่าวสาร ทุกสิทธิ์

หน้าแรกหลังเข้าสู่ระบบ แสดงข่าวสาร รอบการเบิกจ่าย และเบอร์ติดต่อ

  • ผู้ใช้ทั่วไป: อ่านประกาศ
  • Admin กด "แก้ไขประกาศ" เพื่อเพิ่ม/ลบการ์ด แก้หัวข้อ เนื้อหา สี และข้อมูลติดต่อ แล้วกด "บันทึก"

๒.๒ แดชบอร์ด ทุกสิทธิ์

สรุปภาพรวม: จำนวนวัสดุ มูลค่าคงคลัง วัสดุใกล้หมด จำนวนใบเบิกแยกตามสถานะ ใบเบิกล่าสุด และรายการวัสดุใกล้หมด (เฉพาะเจ้าหน้าที่ขึ้นไปจะเห็นข้อมูลคลัง)

๒.๓ สร้างใบเบิก ทุกสิทธิ์

  1. ระบุวันที่เบิกและวัตถุประสงค์
  2. กด "เพิ่มรายการ" ค้นหาวัสดุ (คลิกรูปเพื่อดูภาพใหญ่ได้)
  3. ระบุจำนวนที่ต้องการ (ระบบจำกัดไม่เกินจำนวนเบิกสูงสุดต่อครั้งถ้ามีตั้งไว้)
  4. ตรวจสอบมูลค่ารวม แล้วกด "ส่งใบเบิก"
  5. ระบบแจ้งเลขที่เอกสาร — ใบเบิกจะเข้าสู่ขั้นตอนอนุมัติ

๒.๔ ประวัติใบเบิก ทุกสิทธิ์

User เห็นเฉพาะใบเบิกของตนเอง / เจ้าหน้าที่ขึ้นไปเห็นทั้งหมด สามารถค้นหาได้จากทุกข้อมูล (เลขที่/ผู้เบิก/แผนก) กรองตามสถานะ หน่วยงาน และช่วงวันที่

  • กด "ดู" เพื่อดูรายละเอียดแบบไทม์ไลน์ (ยื่นขอ → อนุมัติ → จ่าย → สิ้นสุด)
  • เปิด/พิมพ์เอกสารใบเบิกและใบจ่ายได้ (ไอคอนเอกสารและไอคอนพิมพ์)

๒.๕ อนุมัติใบเบิก Manager Staff Admin

ทำงานแบบชุด (Batch) — กรองช่วงวันที่ เลือกขอบเขตสิทธิ์ (ขั้นหัวหน้างาน / ขั้นจ่ายพัสดุ)

  1. เลือกช่วงวันที่ แล้วกด "ประมวลผลค้นหาเป้าหมาย"
  2. คลิกบรรทัดใบเบิกเพื่อแตกรายการดูและปรับยอด (อนุมัติ/จ่ายจริง) รายรายการ
  3. ติ๊ก "ค้างจ่าย" หากยังไม่จ่ายรายการนั้น (จ่ายน้อยกว่าเบิกได้ ไม่บังคับค้างจ่าย)
  4. เลือกใบเบิก (ติ๊กหน้าแถว) ได้หลายใบพร้อมกัน
  5. ใส่หมายเหตุ แล้วกด "อนุมัติ" / "ยืนยันการจ่าย" หรือ "ปฏิเสธ"
บังคับปิดงาน ManagerAdmin — ใบเบิกที่จ่ายบางส่วน สามารถสั่งปิดงานเป็น "เสร็จสิ้น" ได้ (รายการค้างจ่ายที่เหลือถูกยกเลิก)

๒.๖ คลังพัสดุ ดู: ทุกสิทธิ์ แก้ไข: Staff+

  • ค้นหา/กรองตามหมวดหมู่ คลิกรูปเพื่อดูภาพใหญ่
  • เจ้าหน้าที่ขึ้นไป: เพิ่ม/แก้ไขวัสดุ กำหนดจุดสั่งซื้อขั้นต่ำ จำนวนเบิกสูงสุดต่อครั้ง และอัปโหลดรูป
  • เฉพาะ Admin ลบวัสดุได้

๒.๗ รับวัสดุเข้าคลัง Staff+

บันทึกการรับพัสดุเข้าสต๊อก — ทำได้ 2 วิธี: กรอกด้วยตนเอง หรือ นำเข้าไฟล์ Excel (มีปุ่มโหลด Template) ระบบปรับปริมาณคงคลังและราคาต่อหน่วยให้อัตโนมัติ

๒.๘ การเคลื่อนไหวพัสดุ Staff+

ค้นด้วยชื่อ/รหัสพัสดุ แสดงประวัติว่ารับเข้าเมื่อไร จ่ายออกไปหน่วยงานใด วันที่เท่าไร พร้อมยอดคงเหลือหลังทำรายการ และหมายเหตุ

๒.๙ จุดสั่งซื้ออัตโนมัติ Staff+

คำนวณจุดสั่งซื้อจากอัตราการใช้จริง แจ้งเตือนรายการที่ต้องสั่ง และออกใบขอซื้อเป็น Excel

  • ปรับพารามิเตอร์ (ช่วงย้อนหลัง, Lead time, วันสำรอง, รอบสั่งซื้อ) แล้วกด "คำนวณใหม่"
  • ตั้งค่ารายวัสดุเฉพาะตัวได้ที่ไอคอนเฟือง
  • กด "คู่มือ & สูตร" ในหน้าจอเพื่อดูสูตรและตัวอย่างการคำนวณ

๒.๑๐ รายงาน Staff+

ด้านบนมี "รายงานด่วน" (การเคลื่อนไหวล่าสุด วัสดุ/หน่วยงานเบิกบ่อย พร้อมจำนวนและมูลค่า) ด้านล่างเลือกรายงานได้ ๗ ประเภท พร้อมตัวกรองช่วงเวลา/หน่วยงาน/หมวดหมู่ และส่งออก Excel

๒.๑๑ Good Issue SAP Staff+

สรุปเฉพาะรายการที่มีการจ่ายออก เลือกตามหมวดวัสดุ เพื่อนำข้อมูลไปลงระบบ SAP (คลังฟิกซ์ 17OSS, Business Type = รหัสหน่วยงาน 2 ตัวหน้า, Department = รหัส 5 หลักหน้า)

๒.๑๒ ผู้ดูแลระบบ Admin

  • จัดการผู้ใช้: แก้ไขชื่อ/แผนก/สิทธิ์ รีเซ็ตรหัสผ่าน ลบผู้ใช้
  • จัดการแผนก: เพิ่ม/ลบหน่วยงาน

๒.๑๓ บันทึกการใช้งาน (Audit Log) Admin

ตรวจสอบว่าใครทำอะไรเมื่อไหร่ (เข้าสู่ระบบ สร้างใบเบิก อนุมัติ/จ่าย รับเข้าคลัง) กรองตามประเภท ผู้ใช้ และช่วงวันที่

๒.๑๔ โปรไฟล์ของฉัน ทุกสิทธิ์

แก้ไขชื่อ-นามสกุล แผนก และเปลี่ยนรหัสผ่านของตนเอง

บทที่ ๓ · ขั้นตอนการทำงานหลัก (Workflow)

ลำดับสถานะใบเบิกตั้งแต่ต้นจนจบ:

ลำดับสถานะผู้ดำเนินการ
1รออนุมัติ (หัวหน้างาน)ผู้ใช้สร้างใบเบิก → รอ Manager/Admin
2รอจ่ายพัสดุหัวหน้างานอนุมัติ → รอเจ้าหน้าที่พัสดุ
3เสร็จสิ้น / จ่ายบางส่วนเจ้าหน้าที่พัสดุจ่ายของ (ตัดสต๊อก + ออกใบจ่าย)
—ปฏิเสธ (หัวหน้างาน/พัสดุ)กรณีไม่อนุมัติในขั้นใดขั้นหนึ่ง
หมายเหตุ: เอกสารใบเบิก/ใบจ่ายเปิดดูได้ทั้งบนคอมพิวเตอร์และมือถือ มีปุ่ม "พิมพ์ / บันทึก PDF" และปุ่ม "ปิดเอกสาร" ในตัว
